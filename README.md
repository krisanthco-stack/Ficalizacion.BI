# Libreta de Fiscalización V17.1 Final

Aplicación PWA municipal orientada a teléfono y tablet para inspección y fiscalización de bienes inmuebles. La ejecución en navegador de escritorio se conserva como compatibilidad funcional y mejora futura de instalación promovida.

## Publicación en GitHub Pages

1. Cargue todos los archivos y carpetas de este paquete en la raíz del repositorio.
2. En GitHub, abra **Settings > Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Seleccione la rama principal y la carpeta **/(root)**.
5. Espere a que GitHub publique la dirección HTTPS.

La aplicación debe servirse por HTTPS para habilitar instalación PWA, cámara y ubicación.

## Instalación prioritaria

- **Android / tablet:** Chrome o Edge > botón **Instalar** o menú > **Instalar aplicación**.
- **iPhone / iPad:** Safari > Compartir > **Agregar a pantalla de inicio**.
- **Escritorio:** la aplicación funciona en navegador; la promoción específica de instalación queda como mejora futura.
