# Instalación de Fiscalización B.I.

La aplicación debe publicarse mediante HTTPS, por ejemplo con GitHub Pages.

## Teléfono o tablet Android
1. Abra la dirección publicada en Chrome o Edge.
2. Pulse **Instalar** dentro de la aplicación o abra el menú del navegador.
3. Seleccione **Instalar aplicación**.

## iPhone o iPad
1. Abra la dirección en Safari.
2. Pulse **Compartir**.
3. Seleccione **Agregar a pantalla de inicio**.

## Computadora
1. Abra la dirección en Chrome o Edge.
2. Pulse **Cómo instalar** dentro de la aplicación o abra el menú del navegador.
3. Seleccione **Instalar Fiscalización B.I.**.

## Actualización
Después de publicar una nueva compilación, abra la aplicación con conexión. El service worker descargará la actualización y recargará la interfaz una vez que el nuevo controlador quede activo.
