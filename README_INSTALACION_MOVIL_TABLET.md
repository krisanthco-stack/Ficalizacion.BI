# Instalación en teléfono y tablet

## Requisitos

- Publicación mediante HTTPS, por ejemplo GitHub Pages.
- Permisos del navegador para cámara, archivos y ubicación cuando sean necesarios.

## Android y tablet

1. Abra la dirección web en Chrome o Edge.
2. Espere a que aparezca el botón **Instalar** en el encabezado.
3. Pulse **Instalar** y confirme.
4. Si el botón no aparece, abra el menú del navegador y seleccione **Instalar aplicación** o **Agregar a pantalla principal**.

## iPhone y iPad

1. Abra la dirección en Safari.
2. Pulse **Compartir**.
3. Seleccione **Agregar a pantalla de inicio**.
4. Confirme el nombre y pulse **Agregar**.

## Trabajo sin conexión

Después de abrir la aplicación al menos una vez con conexión, los archivos principales quedan almacenados en caché. Los expedientes se guardan localmente mediante IndexedDB. Antes de borrar datos del navegador o cambiar de dispositivo, exporte un respaldo JSON.

## Computadora

La aplicación funciona en navegador de escritorio para preparar expedientes, cargar anexos y generar PDF o Word. La promoción específica de instalación para computadora queda reservada como mejora futura.
